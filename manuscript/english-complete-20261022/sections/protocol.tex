\section{The sole normalization protocol}\label{app:M1}
Only stepwise cover-dominating replacement is used.
There is no preliminary simultaneous bilateral clamp, and no claim
that all later corner operations are identities.
The central tile $C$ and remaining non-corner tile $F$ stay fixed in
each local corner operation. The symbol $W$ means a selected corner
tile after the current host representative has been specified.

\begin{proposition}[Exact replacement rule]\label{prop:replacement-rule}
Replace one corner tile $V_i$ in a covering by a unit tile $V_i'$ with
$V_i\cap T_\mu\subseteq V_i'\cap T_\mu$, keeping the other five tiles.
The new family covers the same target. If $V_i$ is neither $C$ nor $F$,
every predicate involving only the unchanged $C,F$ is unchanged.
\end{proposition}
\begin{proof}
A point formerly covered solely by $V_i$ is still in $V_i'$.
All other points retain an unchanged covering tile.
The last statement is equality of the two unchanged sets, not an
invariance statement for corner hosts.
\end{proof}

This rule alone does not preserve a true gap, an injective host choice,
the near/far representative, or a corner's empty central chord.
After an operation that can change a predicate, compute it on the new
actual family. An elimination must handle every resulting case or
give an explicit map to a previously established exclusion.
Leaving the old branch is not, by itself, a contradiction.

For each use of a local operation the reviewer should find:
\begin{enumerate}
\item the replaced tile and its exact old and new projection intervals;
\item target-relative containment and the actual points retained;
\item all possible new branches with the exact earlier exclusions used;
\item the surviving branch's strict inequalities and denominator signs.
\end{enumerate}
The stable $R$ identifiers locate these obligations and their arithmetic
evidence. They do not replace a premise-transfer proof.
The optional one-shot scheme is absent from this edition and cannot be
used as an input in the active proof route. Its old status statements
remain archival, outside the English reading copy.
