# Family 001 — \(S(6)=2\) (candidate)

The following describes the scope of the Lean formalization related to:

- [Six unit squares cannot cover a square of side greater than 2](../../preprints/Six-unit-squares-cannot-cover-a-square-of-side-greater-than-2-October-21-2026/paper.pdf)

## Scope

The shipped `S6Core` library provides a **partial** formalization skeleton for interfaces used in a computer-assisted candidate argument that \(S(6)=2\) (equivalently \(\Pi(2)=7\)).

In the shipped tree, obligations 1–4 are marked closed with 0 `sorry` / extra axioms **in that skeleton**. This does **not** include a full Lean re-proof of every inequality appearing in the long certificate manuscript, nor the omitted `ex/all/` leaf JSON trees.
