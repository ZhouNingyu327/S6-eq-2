## Scope

The shipped `S6Core` library is a **partial** formalization skeleton for a computer-assisted **candidate** argument that \(S(6)=2\) (equivalently \(\Pi(2)=7\) with corrected \(\Pi\)).

In the shipped tree, obligations 1–4 compile with 0 `sorry` / extra axioms **in that skeleton**. Boolean status flags are human-maintained metadata.

### Machine-checked fragments (2026-10-21)

- Primary classifiers `flagsOfTarget` / `flagsOfTargetRotated` (four outer mids; `F∋O`).
- `RoleSelection.ofCover` sixth-tile packaging + body-chart `pullback`.
- `Faithfulness.lean`: API contracts, role packaging lemmas, G5/G1/centre-G2 regressions.
- `ClassificationExample.lean`: rereview counterexample vs legacy MidCandidates wiring.

### Explicitly not claimed

- End-to-end faithfulness of every long-proof covering to these flags.
- Geometric theorem \(S(6)=2\) in Lean.
- Leaf goals of the form `living → True` excluding coverings.
- `reduction_to_standardForm` constructing a concrete covering with proved fields.
