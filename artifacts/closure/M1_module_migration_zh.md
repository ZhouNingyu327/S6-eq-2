# 规范化主协议与模块迁移说明

**主协议（公开包）：** 短文命题 3.3 — 对角块做支配扩大后，若可能改变宿主/缺口，则**逐步重新分类**。单个算子幂等，并不蕴含“此后一切局部夹取均为恒等”。

**可选强方案：** 附录 A / 长稿 §2.1 的一次全局双侧夹取（M1.1–M1.3）。在未完成逐模块前提迁移证明前，不升格为主协议。

## 各模块族：预处理后的预期输入与填平缺口时的去向

| 模块族 | 典型轮次 | 逐步重分类下的预期输入 | 夹取/扩大填平真缺口时 |
| --- | --- | --- | --- |
| G5 / 早期中心 | R2–R8 | `F∋O` 或相应 `k∈{0,1,2}`；角块可经一次支配扩大 | 缺口消失 → 落入“外边相接”叶，由已排除的相接命题处理，不循环调用标准化 |
| 近端残差 G2 | R13–R28 | 唯一 mid 在 `F`∩BOTTOM；宿主注入 (RIGHT,TOP,LEFT) 代表元 | 填平 → 近端相接/角块重复归属叶；重分类后离开残差 G2 |
| 远端归约 | R29–R39 | 预处理后的自由角块记为 `W`（与近端未预处理 `F` 区分）；中心块不动 | 填平 LEFT/RIGHT/TOP 缺口 → 转入相接或标准形前提已满足的远端叶 |
| 最终形 | M8–M11 / R40–R64 | 远端标准形接缝点、面积与直径约束 | 不在最终形内迭代标准化；若输入未达标准形，应在远端阶段重分类而非在 M8–M11 内补做 |

## 附录 A 强夹取

双侧 `β` 夹取是**可选**候选工具。主链审稿与复现以短文逐步重分类为准；若将来升格强方案，须按上表补全“前提保持 / 分支迁移”证明后再改口径。
