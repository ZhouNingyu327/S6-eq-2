# 规范化主协议与模块迁移说明

**主协议（公开包）：** 短文命题 3.3 — 对角块做支配扩大后，若可能改变宿主/缺口，则**逐步重新分类**。单个算子幂等，并不蕴含“此后一切局部夹取均为恒等”。

**可选强方案（延期）：** 附录 A / 长稿 §2.1 的一次全局双侧夹取（M1.1–M1.3）。**不**升格为主协议。本包**不声称**已完成逐模块前提迁移证明。

---

## 强方案为何保持延期

若要把 M1.1–M1.3 升为主协议，须对下表每一排除族写出：

1. **前提保持：** 全局夹取后，该模块用到的假设仍成立（或覆盖已离开该类）；
2. **分支迁移：** 若夹取填平真缺口，覆盖落入已排除的相接叶，并给出旧约束 → 新叶 ID 的显式对应；
3. **不暗含“未标准化 \(W\)”：** 标“原 \(W\)”的模块须核对并不依赖未夹取自由角（长稿 M1.3 有主张；此处未做独立重证）。

在 (1)–(3) 成为可审读证明之前，公开核验只走**逐步重分类**。
